# Portfólio de agentes e skills de IA

Biblioteca de **referências externas** para avaliar e reutilizar em projetos futuros. Esta pasta é independente do código do Context Mode.

> Os seis projetos abaixo **não foram instalados, clonados nem executados**. Os links apontam para os repositórios dos autores. Antes de incorporar código, confira licença, versões, dependências e permissões.

|---|---|---|

| Wshobson Agents | https://github.com/wshobson/agents | Agentes, skills e plugins para desenvolvimento, testes e infraestrutura |

## Organização
- [Catálogo e avaliação](CATALOGO.md): detalhes, aplicações e critérios.
- [Guia de adoção](GUIA-DE-ADOCAO.md): como experimentar sem comprometer projetos existentes.

## Uso em futuros projetos
1. Definir o problema e selecionar apenas o recurso relevante.
2. Verificar o repositório original, licença e versão atual.
3. Revisar instruções, scripts, dependências e acessos solicitados.
4. Testar em ambiente isolado antes de integrar.
5. Documentar a versão utilizada, alterações e resultados.
